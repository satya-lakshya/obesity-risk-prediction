# Obesity Risk Prediction using Ensemble Learning

This repository contains a machine learning project focused on predicting obesity risk based on lifestyle and biometric data. The project follows a complete data science workflow and includes multiple ensemble learning techniques.

---

## 📚 Project Overview

- **Goal**: Predict obesity risk categories using ML classification models
- **Dataset**: Obesity risk dataset 
- **Methods Used**:
  - Logistic Regression, KNN, Decision Tree
  - Ensemble Methods: Bagging, AdaBoost (others planned)
